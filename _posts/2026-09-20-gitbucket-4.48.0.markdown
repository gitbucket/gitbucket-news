Today, we are pleased to announce the availability of [GitBucket 4.48.0](https://github.com/gitbucket/gitbucket/releases/tag/4.48.0), the Scala-based self-hosting Git server.

This release includes a database migration that affects the core `ACCOUNT` table. We strongly recommend backing up your database before upgrading.

Here are the major changes in this version.

## Numeric account IDs in the GitHub-compatible Web API

GitBucket now assigns a unique numeric ID to each user and organization account. The GitHub-compatible API returns this ID for user and organization resources, improving compatibility with GitHub API clients.

The API also supports retrieving an account by its numeric ID through `GET /api/v3/user/{id}`.

## Internal API changes

The internal APIs that could be used by controllers have changed in this release. Plugins that provide custom controllers may require updates before they can be used with GitBucket 4.48.0. Please verify plugin compatibility before upgrading.

## Safer account management

GitBucket now correctly prevents the last administrator account from being deleted or downgraded. A new **Danger Zone** tab has also been added to user settings, where users can delete their own accounts.

![Danger Zone in user settings]({{site.baseurl}}/images/gitbucket-4.48.0/user_danger_zone.png)

This release also includes other improvements and bug fixes. See all closed issues in [4.48.0](https://github.com/gitbucket/gitbucket/issues?q=is%3Aclosed+milestone%3A4.48.0) for details.

Enjoy GitBucket!
